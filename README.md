# نور — NOUR · Application Islamique Complète

## Déploiement sur GitHub Pages

### Étape 1 — Créer un dépôt GitHub
1. Va sur github.com → bouton "New"
2. Nom : **nour-app** · Visibilité : **Public**
3. Cliquer "Create repository"

### Étape 2 — Uploader les fichiers
1. "uploading an existing file"
2. Glisser-déposer les 4 fichiers : index.html · manifest.json · sw.js · README.md
3. Commit : "Initial commit — Nour App"

### Étape 3 — Activer GitHub Pages
1. Settings → Pages
2. Source : "Deploy from a branch" → main → / (root) → Save
3. Attendre 2 minutes
4. Lien : **https://TON-USERNAME.github.io/nour-app/**

### Installer comme application (PWA)
**iPad/iPhone (Safari)** : Partager → "Sur l'écran d'accueil"
**Android (Chrome)** : Menu ⋮ → "Ajouter à l'écran d'accueil"
